# Планировщик рекламы

Приложение для учета регулярных рекламных постов, закрепов и напоминаний.

Что умеет:

- хранить площадки отдельно от графиков публикаций;
- задавать период, правило публикаций и статус оплаты;
- отмечать одной датой, до какого числа посты уже размещены;
- показывать на главной странице только актуальные выкладки и отставания;
- напоминать про обновление закрепов по интервалу.

## Запуск

```bash
python3 /Users/darya_botova/Documents/Подборки/ads_tracker_app/app.py
```

По умолчанию приложение откроется на:

```text
http://127.0.0.1:8765
```

## Где хранятся данные

SQLite-файл создается автоматически:

```text
/Users/darya_botova/Documents/Подборки/ads_tracker_app/data/ads_tracker.db
```

## Как пользоваться

1. Сначала добавь площадки.
2. Потом добавь по каждой площадке график публикаций.
3. В поле `Размещено до` указывай дату включительно.
4. На главной странице смотри:
   - что нужно выложить сегодня;
   - где есть просрочка;
   - сколько постов уже закрыто по плану;
   - какие закрепы пора обновить.

## Railway

Для Railway проект готов к деплою через `Dockerfile`.

Что важно:

- для SQLite нужен `Volume`, иначе база будет теряться при пересборке;
- приложение слушает порт из переменной `PORT`;
- если у Railway есть `RAILWAY_VOLUME_MOUNT_PATH`, база будет храниться там автоматически.

Рекомендуемый volume mount path:

```text
/data
```

## Важное ограничение

Сейчас в приложении нет авторизации пользователей.
Если выложить его в интернет в текущем виде, любой, у кого есть ссылка, сможет менять данные.
